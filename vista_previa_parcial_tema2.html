Pregunta 1Parcial POO T2 - Ej. 1: Verdadero o Falso24 pts

Ejercicio 1 (24 puntos). Indicá si cada afirmación es Verdadera o Falsa (4 ptos. c/u).

  1. Una interface puede extender otra interface.
  2. Al declarar una variable del tipo de una clase se crea un objeto de esa clase.
  3. El calificador final aplicado a un atributo impide su reasignación.
  4. Una clase abstracta no puede tener constructores.
  5. El polimorfismo permite que un mismo mensaje se comporte diferente según el objeto.
  6. Dos métodos en la misma clase pueden tener igual nombre e igual lista y tipo de parámetros.

Retroalimentación general

  1. V — Una interface puede extender una o varias interfaces con extends.
  2. F — Declarar la variable sólo crea una referencia (vale null si es atributo); el objeto se crea con new.
  3. V — Un atributo final se asigna una sola vez (en la declaración o en el constructor).
  4. F — Puede tenerlos: no se invocan con new, sino desde las subclases mediante super(...).
  5. V — El método que se ejecuta se decide en ejecución según el tipo real del objeto (enlace dinámico).
  6. F — Tendrían la misma firma: es un error de compilación. La sobrecarga exige listas de parámetros distintas.

Retroalimentación general

Solución completa:

abstract class Producto {
    protected String nombre;
    protected double precio;
    protected int cantidad;
    public Producto(String nombre, double precio, int cantidad) {
        this.nombre = nombre;
        this.precio = precio;
        this.cantidad = cantidad;
    }
    public abstract double calcular();
    public void mostrar() {
        System.out.println(nombre + ": $" + calcular());
    }
}
class ProductoLocal extends Producto {
    public ProductoLocal(String nombre, double precio, int cant) {
        super(nombre, precio, cant);
    }
    public double calcular() { return precio * cantidad; }
}
class ProductoImportado extends Producto {
    private double recargo;
    public ProductoImportado(String nombre, double precio, int cantidad, double recargo) {
        super(nombre, precio, cantidad);
        this.recargo = recargo;
    }
    public double calcular() {
        return precio * cantidad * (1 + recargo);
    }
}
public class Tienda {
    public static void main(String[] args) {
        Producto p1 = new ProductoLocal("Lapiz", 50.0, 3);
        Producto p2 = new ProductoImportado("Mouse", 100.0, 2, 0.30);
        p1.mostrar();
        p2.mostrar();
    }
}

calcular() es abstracto en Producto y cada subclase lo implementa a su manera; mostrar() lo invoca por enlace dinámico. Los atributos protected permiten usar precio y cantidad directamente en las subclases.
